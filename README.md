# Система виявлення плагіату в студентських роботах

## Опис проєкту
Автоматизована інформаційна система для перевірки текстових робіт на наявність збігів із документами, збереженими в локальній базі даних.

## Можливості
- Завантаження текстових документів.
- Збереження робіт у базі даних SQLite.
- Порівняння текстів.
- Розрахунок схожості та оригінальності.
- Експорт результатів перевірки.

## Технології
- C#
- WPF
- .NET Framework 4.8
- SQLite

## Запуск
Завантажте архів із розділу **Releases**, розпакуйте його та запустіть `CourseWork_Zubarev.exe`.

## Примітка
Система визначає приблизну текстову схожість із документами, що зберігаються в локальній базі даних.
